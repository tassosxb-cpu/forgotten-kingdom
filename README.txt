THE FORGOTTEN KINGDOM — ASHEN OATH 3.1
Isometric action RPG prototype for GitHub Pages. Upload all files, including exile-hero.png to repository root and commit. Move with WASD / arrow keys or tap/click the map. Click a nearby enemy or press Space to attack; Q casts shadow magic; 1/2 use life/mana potions; I opens inventory. Enemies pursue, bosses drop rare loot, items auto-pickup. Local save and PWA install/offline/update support.
